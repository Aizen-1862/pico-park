# CATNAP — Co-op Puzzle Park

A colourful 2D online multiplayer platform puzzle game inspired by the *teamwork* idea behind cooperative puzzle platformers. It uses original characters, code, visuals, and level layout.

## Features
- Create a private room and invite friends with a 6-character code
- Up to 8 players in one room
- Colourful cat characters with live multiplayer movement
- Platforming, jumping, a shared key, and a team exit objective
- Keyboard and mobile touch controls
- Responsive browser UI

## Run locally
1. Install Node.js 18 or newer.
2. Run `npm install`.
3. Run `npm start`.
4. Open `http://localhost:3000` in your browser.
5. Share your room code with friends on the same deployed server.

## Deploy on Render
- Create a **Web Service** from this repository.
- Runtime: Node
- Build command: `npm install`
- Start command: `npm start`
- No environment variables are required. Render provides `PORT` automatically.
- WebSocket connections use the same host as the website.

## Controls
- Move: A/D or Left/Right arrows
- Jump: Space, W, or Up arrow
- Mobile: on-screen buttons
